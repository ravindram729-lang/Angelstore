ANGELSTORE - RENDER DEPLOYMENT PACKAGE

This folder contains the application runtime files and required frontend assets.
Audit reports, test scripts/results, Windows .bat launchers, local runtime data,
local lock files, and local environment secrets are intentionally excluded.

DEPLOY
1. Extract this ZIP.
2. Push the CONTENTS of this folder to a new GitHub repository (not the ZIP itself).
3. In Render, choose New + -> Blueprint and connect that repository.
4. Render will read render.yaml. Review the service name, plan, and persistent disk.
5. Set the required secret environment values in Render:
   - ANGELSTORE_ADMIN_USER
   - ANGELSTORE_ADMIN_PASS (use a strong unique password)
   - ANGELSTORE_OFFSITE_BACKUP_URL / TOKEN / ENCRYPTION_KEY only if offsite backup is configured.
6. Confirm ANGELSTORE_AUTH_SECRET is generated by Render and the persistent disk is mounted
   at /var/data/angelstore.
7. Confirm ANGELSTORE_CORS_ORIGIN matches the actual frontend origin before launch.

IMPORTANT
- Do not upload .env files containing real secrets.
- Do not upload local data.json, uploads, backups, or angelstore.server.lock.
- Render's persistent disk is required for the JSON database and uploaded documents.
- This package does not migrate any existing local customer/payment data.
- Before production use, verify environment variables, backup/restore, login,
  payment uploads, document uploads, and health endpoint in the deployed service.
